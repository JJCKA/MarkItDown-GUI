# 二次开发指南

## 环境搭建

```bash
# Python 虚拟环境
python -m venv MDGUI
MDGUI\Scripts\activate
pip install -r requirements.txt

# 前端
npm install

# 启动开发
npm run electron:dev
```

## 添加新文件格式

1. `backend/prompts/builtin.py`：将扩展名加入对应分类集合（`IMAGE_EXTENSIONS` / `AUDIO_EXTENSIONS` / `DOCUMENT_EXTENSIONS` / `TABLE_EXTENSIONS` / `CODE_EXTENSIONS`）
2. `src/components/FileTree.tsx`：将扩展名加入 `SUPPORTED_EXTS`，可选添加新的 SVG 图标到 `FileIcon` 函数
3. markitdown 引擎会自动处理格式解析，无需额外代码

## 添加新 LLM 功能

1. `backend/prompts/builtin.py`：定义新的 Prompt 模板，加入 `PROMPTS` 注册表
2. `backend/core/converter.py`：在 `convert_with_llm` 中添加处理步骤（参考 Step 2-5）
3. 前端设置页面 `SettingsPage.tsx`：添加开关 UI
4. `src/stores/appStore.ts`：添加对应状态字段

## 自定义主题

所有颜色变量定义在 `src/styles/theme.css` 的 `:root` 选择器中。修改对应变量即可全局生效。

Markdown 渲染样式在 `.md-preview` 规则块中，覆盖标题、表格、代码块等组件的视觉样式。

## 添加新组件

1. 在 `src/components/` 创建 `.tsx` 文件
2. 从 `useAppStore` 获取所需状态
3. 在 `App.tsx` 中引入并渲染

所有组件使用内联样式，直接引用 CSS 变量名（如 `color: 'var(--muted)'`）。

## 添加键盘快捷键

编辑 `src/hooks/useKeyboard.ts`，在 `handleKeyDown` 中添加新的按键判断。

## 缓存系统

缓存管理器 `backend/core/cache.py` 将所有转换结果存储在单一 `~/.markitdown-ui/cache.json` 文件中。转换完成后自动写入缓存，导出编辑后的内容时也会更新缓存。

历史记录（`config.json` 的 `history.items`）只存元数据，不存 markdown 内容。`get_history` 端点自动将两者合并返回。修改缓存逻辑时需同时考虑这两个数据源。

## 扩展后端 API

1. 在 `backend/api/` 创建路由
2. 在 `backend/main.py` 中注册
3. 前端在 `src/api/client.ts` 添加对应的请求函数

## 修改 LLM Provider

支持任意 OpenAI 兼容端点。如需接入原生 Anthropic API 或其他协议，修改 `backend/core/llm_client.py` 中的请求格式。

## 运行测试

```bash
MDGUI\Scripts\python.exe -m pytest backend\tests\ -v
```

## 打包

```bash
scripts\build.bat
```

分三步：`vite build` → `PyInstaller backend/main.py` → `electron-builder`。最终产物 `release/MarkItDown GUI x.x.x.exe`。

如需安装包模式（NSIS），在 `electron-builder.yml` 中将 `portable` 改为 `nsis`，并确保 WinCodeSign 缓存正常。
