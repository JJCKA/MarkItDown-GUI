# MarkItDown GUI 用户指南

## 快速开始

直接运行打包好的 `MarkItDown 2.0.0.exe`，双击启动。

### 基本使用

1. 侧边栏左下角文件夹图标 → 打开文件 或 打开文件夹
2. 文件树中展开目录，点击文件（Ctrl/Shift 多选）
3. 底部「转换」→ 基础 Markdown 转换；「LLM 转换」→ LLM 增强处理
4. 中央区域渲染预览 Markdown，可切换源码/预览模式
5. 工具栏「复制」/「导出」保存内容

### LLM 配置

设置页面（侧边栏齿轮图标）：

- **提供商**：OpenAI / Anthropic / 自定义端点
- **API Key**：你的 API 密钥
- **Base URL**：API 地址，切换提供商会自动填充
- **模型**：如 `gpt-4o`、`claude-sonnet-4-6`
- **最大 Tokens** / **Temperature**：可调
- 点击「测试连接」验证，修改后自动保存

### LLM 高级功能

通过 ▾ 按钮或设置页面启用：

- **图片描述**：任意图片文件或 DOCX/PPTX/PDF 内嵌图片的 AI 描述
- **全文内容总结**：提取核心主题、关键要点、结构分析
- **复杂表单清洗**：将 Word/PDF 中的排版表格展平为清晰 Markdown

### 侧边栏

- **文件**：文件树，展开/折叠目录
- **已转换**：已转换文件列表，点击可回溯结果
- **底部图标**：打开（文件夹）· 设置（齿轮）· 历史（时钟）

### 底部控制栏

- `◀` 展开/收起侧边栏
- `<>` 源码 / 渲染预览切换
- 状态文字 / 日志 / 字符词数 / 耗时
- `转换`（蓝色） / `LLM 转换`（粉色）
- `▾` LLM 功能快速开关

### 菜单栏

- 文件：打开文件 · 打开文件夹 · 导出 · 关闭
- 编辑：复制
- 视图：侧边栏 · 源码模式 · 日志面板
- 转换：转换 · LLM 转换
- 帮助：关于

### 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+O | 打开文件 |
| Ctrl+Shift+O | 打开文件夹 |
| Ctrl+S | 导出 |
| Ctrl+Enter | 转换 |
| Ctrl+Shift+Enter | LLM 转换 |
| Ctrl+B | 侧边栏 |
| Ctrl+H | 历史记录 |
| Ctrl+, | 设置 |
| Ctrl+J | 日志面板 |
| Escape | 关闭弹窗 |

| 类别 | 扩展名 |

| 表格 | .xlsx .xls .csv .json .xml .yaml |
| 文本 | .txt .md .html |
| 图片 | .jpg .jpeg .png .gif .bmp .webp .svg .tiff |
| 音频 | .mp3 .wav .m4a .flac .aac .ogg .wma |
