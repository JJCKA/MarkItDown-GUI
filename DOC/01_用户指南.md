# MarkItDown GUI 用户指南

## 快速开始

直接运行打包好的 `MarkItDown GUI.exe`，双击启动。

### 基本使用

1. 侧边栏左下角文件夹图标 → 打开文件 或 打开文件夹（也可直接拖拽文件到窗口）
2. 文件树中展开目录，点击文件（Ctrl/Shift 多选）
3. 底部「转换」→ 基础 Markdown 转换；「LLM 转换」→ LLM 增强处理
4. 中央区域渲染预览 Markdown，可切换预览/源码/对比模式
5. 工具栏「复制」/「导出」保存内容

### 拖拽支持

直接将文件或文件夹从资源管理器拖放到窗口中即可打开。拖放时会显示蓝色虚线浮层提示。

### LLM 配置

设置页面（侧边栏齿轮图标）：

- **提供商**：OpenAI / 自定义端点
- **API Key**：你的 API 密钥
- **Base URL**：API 地址，切换提供商会自动填充
- **模型**：如 `gpt-4o`、`deepseek-chat`
- **最大 Tokens** / **Temperature**：可调
- 点击「测试连接」验证，修改后自动保存（500ms 防抖）

### LLM 高级功能

通过 ▾ 按钮或设置页面启用：

- **图片描述**：任意图片文件或 DOCX/PPTX/PDF 内嵌图片的 AI 描述
- **音频转录**：将音频文件转录为文字
- **全文内容总结**：提取核心主题、关键要点、结构分析
- **复杂表单清洗**：将 Word/PDF 中的排版表格展平为清晰 Markdown

### 视图模式

底部控制栏左侧的图标按钮切换三种视图：

- **预览模式**（眼睛图标）：渲染后的 Markdown 效果
- **源码模式**（代码图标）：可编辑的 Markdown 源文本，修改后预览实时更新
- **对比模式**（分屏图标）：左侧显示 markitdown 原始提取文本，右侧显示最终转换结果

### 转换队列

选择多个文件进行转换时，会自动弹出队列面板：

- 逐文件显示转换状态（等待中/转换中/完成/失败/已取消）
- 支持「取消剩余」中断批量转换
- 支持「全部导出」将完成的文件导出到指定目录
- 转换完成后可清除队列

### 侧边栏

- **文件**：文件树，展开/折叠目录
- **已转换**：已转换文件列表，点击可回溯结果
- **底部图标**：打开（文件夹）· 设置（齿轮）· 历史（时钟）· 统计（柱状图）

### 底部控制栏

- `◀` 展开/收起侧边栏
- `👁/<>` 预览 / 源码切换
- `⊞` 对比视图开关
- 状态文字 / 日志 / 字符词数 / 耗时
- 进度条（批量转换时显示）
- `转换`（蓝色） / `LLM 转换`（粉色）+ `▾` LLM 功能快速开关

### 历史记录

侧边栏底部时钟图标打开历史记录面板：

- 显示所有转换记录，包含文件名、时间戳、字符数、耗时、成功/失败状态
- 已缓存的记录带淡蓝色背景标记，可点击查看转换结果
- 未缓存的记录为普通背景，仅显示元数据
- 底部显示当前缓存保留条数上限

### 转换统计

侧边栏底部柱状图图标打开统计面板：

- 总转换次数 / 成功率 / 总字符数 / LLM 调用次数 / 平均耗时 / 失败次数
- 数据持久化保存，重启后不丢失

### 缓存设置

设置页面「历史记录与缓存」区域：

- **最大缓存**：设置保留的缓存条数上限（旧记录自动覆盖）
- **清除缓存**：删除所有缓存的转换结果（弹窗二次确认）
- **清除历史记录**：删除所有历史记录（弹窗二次确认）

缓存文件存储在 `~/.markitdown-ui/cache.json`，所有缓存集中在一个文件中。

### 菜单栏

- 文件：打开文件 · 打开文件夹 · 导出 · 关闭
- 编辑：复制
- 视图：侧边栏 · 预览模式 · 源码模式 · 对比模式 · 日志面板
- 转换：转换 · LLM 转换
- 帮助：关于

### 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+O` | 打开文件 |
| `Ctrl+Shift+O` | 打开文件夹 |
| `Ctrl+S` | 导出 Markdown |
| `Ctrl+Enter` | 普通转换 |
| `Ctrl+Shift+Enter` | LLM 转换 |
| `Ctrl+B` | 切换侧边栏 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+H` | 历史记录 |
| `Ctrl+J` | 切换日志面板 |
| `Ctrl+Shift+V` | 切换对比视图 |
| `Escape` | 关闭弹窗 / 返回编辑器 |
